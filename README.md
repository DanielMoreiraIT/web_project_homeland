# Tripleten web_project_homeland

# De Pátria para Pátria

Projeto desenvolvido durante o Sprint 5 do curso de Desenvolvimento Web da TripleTen.

A página apresenta cidades natais de funcionários da TripleTen e foi desenvolvida com foco em responsividade, adaptação do layout para diferentes tamanhos de tela e fidelidade ao design fornecido no Figma.

## Funcionalidades

- Layout responsivo para desktop, tablet e dispositivos móveis
- Adaptação do conteúdo para diferentes larguras de tela
- Uso de imagens e tipografia conforme o design do Figma
- Estrutura organizada utilizando a metodologia BEM

## Tecnologias e técnicas utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Metodologia BEM
- Estrutura de arquivos BEM Flat
- Fonte Inter carregada localmente
- Design responsivo
- Git e GitHub
